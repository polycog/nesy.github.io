Overview

Why Neurosymbolic Agents?

AI research and engineering are rapidly shifting from static LLM prompting to building and deploying autonomous agents. While LLM-based agents excel at low-stakes information processing or human-in-the-loop tasks, they remain unreliable for fully autonomous, mission-critical deployments where unmitigated execution errors compound over multi-step tasks. Unlocking higher-stakes autonomy requires replacing brittle, purely stochastic inference loops with principled, trustworthy agent architectures.

Bridgining this technical gap, we are presenting the AI community with cognition, an integrative Python framework that harmonizes classical knowledge representation and reasoning, decision theory, and automated planning with modern language models.

Learning Outcomes

What You'll Build

Participants develop a trustworthy neurosymbolic agent from the ground up — an assistant that handles natural language requests while keeping operation safe and goal-directed by learning to…

  1. Author a Decision Process
    A state-driven alternative to rigid workflows in which expert knowledge dynamically determine which actions are valid & preferred.
  2. Embed Decision-Making within a Perceive-Decide-Act Loop
    Sensors and actuators connect decisions with real-world information sources & tools.
  3. Enable Flexible Language Interfaces
    LLM(s) bidirectionally translate between natural language and typed, structured domain knowledge.
  4. Maintain a Knowledge Graph
    An explicit, queryable world model updated from agent perception, processing, and action.
  5. Reason Symbolically
    Generate multi-step plans with state-space search and trace execution to verify the agent's behavior.

Audience

Who Should Attend

This lab is for the general AAAI audience: researchers, engineers, and students who want a practical way to build agents that are more reliable than prompting alone. No prior neurosymbolic experience is needed.

  • Basic exposure to MDPs/decision theory

Setup

Before You Arrive

Conference Wi-Fi is unpredictable, so please do these steps before the lab. They should take about 10 minutes.

Coding Agents

The cognition library is built to play nice with Claude Code - point it to the Polycog website and 🪄.

  1. Install Python 3.13 or newer

    Check your version. If you need to install, we recommend anaconda or the official installer from python.org.

    shell 
    python3 --version
  2. Create a virtual environment and install cognition
    shell 
    mkdir nesy-lab && cd nesy-lab
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install polycog-cognition
  3. Configure a language model

    You'll need an OpenAI API key, or access to any OpenAI-compatible endpoint (including a local model server).

    shell 
    export OPENAI_API_KEY="sk-..."
# optional: an OpenAI-compatible server
export OPENAI_BASE_URL="http://localhost:1234/v1"
  4. Run the smoke test

    If this prints "ok", you're ready.

    shell 
    python -c "import cognition; print('ok')"   # placeholder check
No API Key? No Problem.

Supplied materials include recorded LLM responses, so you can follow along offline. You can also pair up with a neighbor.

FAQ

Common Questions

How do I register?

Labs are part of the AAAI-27 Tutorial & Lab Forum. Register through the AAAI-27 conference site.

Can I attend without a laptop?

Yes. Talks and live demos stand on their own, and you can pair with a neighbor during hands-on segments. You'll get the most out of it with your own setup.

Do I need a paid LLM account?

No. Any OpenAI-compatible endpoint works, including a local model server, and the materials include recorded responses so you can view them offline.

Is cognition open source? Can I use it in my research?

The cognition library is fair-source: the code is public on GitHub.
